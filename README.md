### 学生版年付和星耀版月付有什么区别？

学生版需一次支付 **¥84/年**，每月提供 **50GB**；星耀版可按 **¥25/月**购买，每月提供 **150GB**。前者是低流量年付小包，后者的付款周期较短、流量额度更高。以上均为未预先叠加新人优惠码的截图标价。
